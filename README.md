 EV Charging Station Usage Analysis
 Project Overview
 This project simulates and analyzes **EV charging station usage** across major Indian cities during 2024.  
 The focus is on **insights** using **NumPy + Pandas only** (no visualization libraries).

 Tech Stack
- Python 3.10+
- NumPy
- Pandas
- Matplotlib

 Repository Structure
- `data/` → Contains simulated dataset 
- `Data_Generator/` → Data generation script  
- `notebooks/` → Jupyter notebook with full analysis  
- `README.md` → Project documentation  

 Features
- Generates synthetic EV charging dataset (hundreds of thousands of rows)  
- City-level and station-level revenue analysis  
- Peak vs non-peak usage study  
- Monthly and seasonal demand analysis  
- EV vs petrol cost savings calculation

 Future Extensions
- Add real-world EV datasets  
- Include tariff modeling (dynamic pricing)  
- Predict future demand using ML models
